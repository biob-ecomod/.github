# About
This organisation centralises current and past projects of the Ecological Modelling team at the Bonner Institut für Organismische Biologie (BIOB), Rheinische-Friedriche Universität Bonn, Germany.
Research undertaken in the team focuses on understanding the processes underlying the formation, maintenance, and spatiotemporal dynamics of biodiversity—from local to global scales and across various levels of ecological organization. 
The research group employs a variety of methods, including fieldwork, data analysis, and macroecology, but focuses primarily on mechanistic simulation modeling.

# Current projects

- [MetaRange](https://metarange.github.io/) : a lightweight, flexible framework for developing and running spatially-explicit, population-based ecological models. MetaRange is highly customisable (the user specifies model components through functions), extremely fast, and supports dispersal, species interactions, and metabolic components.
- [MoF3D](https://github.com/julianoscabral/MoF3D) : a 3D functional-structural tree model (FSTM) deriving realistic 3D structures of tree communities from explicit modelling of the carbon cycle, using the growth grammar Java-based language [GroIMP](https://grogra.de/).
- [MoDVE](https://github.com/01zc/MoDVE) : an individual-based model of epiphyte communities in a 3D forest landscape, supporting integration with MoF3D for the derivation of epiphyte-available substrate and [micropoint](https://github.com/ilyamaclean/micropoint) as input for the microclimatic data.
- [SERES](https://github.com/lesteveztobar/seres) : a three-dimensional, individual-based model of epiphyte colonisation driven by downscaled within-canopy microclimate.
- [BMIP](https://github.com/biob-ecomod/BMIP-ecomods) 🔏: our contribution to the [GEO BON](https://geobon.org/ecocode-modelling-life-on-earth/) Biodiversity Model Intercomparison initiative. We use MetaRange to derive spatio-temporal abundance predictions for a set of case studies, with the goal of comparing the model's performance and conclusions with a range of other correlative and process-based ecological models. Read the protocol preprint for more info about BMIP.
